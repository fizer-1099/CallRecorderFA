# ضبط مکالمه (CallRecorderFA)

پروژه آزمایشی اندروید با رابط فارسی، تشخیص وضعیت تماس، تلاش برای ضبط خودکار از میکروفون و فهرست/اشتراک‌گذاری فایل‌ها.

## محدودیت مهم
این نسخه یک نمونه اولیه است، نه ضبط‌کننده تضمینی تماس دوطرفه. Android و سازنده گوشی ممکن است صدای تماس را از میکروفون مسدود کنند. اجرای سرویس میکروفون از پس‌زمینه نیز در نسخه‌های جدید Android محدود است؛ بنابراین شروع خودکار ممکن است روی برخی گوشی‌ها شکست بخورد. برنامه فعلاً فقط تلاش می‌کند صدای ورودی میکروفون را ضبط کند و راهکار privileged / پیش‌فرض تماس نیست.

## ساخت APK
پروژه را در GitHub بارگذاری کنید. از Actions، گردش کار Build Android APK را اجرا کنید و فایل artifact را دریافت کنید.
