# ضبط مکالمه (CallRecorderFA)

نمونه اولیه اندروید با رابط فارسی: تشخیص تماس، ضبط خودکار با میکروفون، فهرست و اشتراک‌گذاری فایل‌ها.

## روش کار (نسخه اصلاح‌شده)
۱. برنامه را باز کنید و دسترسی‌های میکروفون، وضعیت تلفن و اعلان‌ها را بدهید.
۲. روی «فعال‌سازی ضبط خودکار» بزنید (باید برنامه باز باشد). یک اعلان دائمی نشان داده می‌شود.
۳. برنامه را از بهینه‌سازی باتری مستثنی کنید (Unrestricted).
۴. تماس بگیرید؛ با شروع تماس ضبط شروع و با پایان تماس ذخیره می‌شود. وضعیت و خطاها بالای صفحه نمایش داده می‌شوند.

بعد از ریستارت گوشی یا بستن اجباری برنامه، دوباره باید برنامه را باز و فعال کنید.

## محدودیت مهم
اندروید ۱۰ به بعد صدای طرف مقابل را از برنامه‌های عادی مسدود می‌کند. اگر فایل بی‌صدا بود، «منبع صدا» را عوض کنید و تماس را روی بلندگو بگذارید. روی بعضی گوشی‌ها فقط همین راه جواب می‌دهد.

## ساخت APK
پروژه را در GitHub بارگذاری کنید، از Actions گردش‌کار Build Android APK را اجرا کنید و artifact را دانلود کنید.
